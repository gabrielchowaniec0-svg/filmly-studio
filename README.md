# Filmly Studio

Digital art assets, a browser editor and a tiny language (**FilmScript**) for making 2D short films —
built so a person and Claude can work on the same files. Everything renders from vectors, so a film
exports to MP4 at any resolution (720p … 8K) and frame rate the browser's encoder allows.

- **Live editor:** https://filmly-studio.netlify.app (Netlify, auto-deploys from `main`)
- **Language reference:** [docs/FILMSCRIPT.md](docs/FILMSCRIPT.md) · **Plan:** [docs/PLAN.md](docs/PLAN.md)

## Run it

```
node scripts/serve.mjs      # http://localhost:5173  (no npm install needed)
node --test tests/*.test.mjs          # language, engine, asset and MP4 muxer tests (needs ffmpeg for the muxer test)
```

## What's in the box

| | |
|---|---|
| Rig | `humanoid` — 3/4-view person generated by `scripts/rigs/humanoid/` (face, hair, body, clips modules): 32 hairstyles, 19 hats, 24 tops, 9 bottoms, 7 shoes, facial hair, eyewear, brow styles, freckles, 6 hand shapes, 8 body builds, 59 animation clips (9 walk styles, idles, 30+ gestures, talk variants) |
| Characters | 24 people + a Character Creator for variants (`character x from y hair=afro top=varsity …`) |
| Animation | IK-planted walks/runs, cross-fades, gesture holds, natural blinks, listeners watch the speaker, squash turns, viseme lip-sync driven by real audio |
| Backgrounds | 26 scenes (interiors, exteriors, spooky mansion, space, underwater…), some with foreground layers |
| Props | 67 props; characters can hold, give and drop them |
| Effects | 17 deterministic effects: rain, snow, fog, lightning, fireflies, spotlight, sepia, film grain… |
| Sounds | 84 procedurally generated sounds (CC0): 59 SFX, 13 music loops, 12 ambiences |
| Voices | Browser voices by default (free, preview only) + Kokoro (free, in-browser) + OpenAI, ElevenLabs, Google, Gemini, Azure, Polly, Deepgram, Cartesia, Hume, Fish, LMNT, any OpenAI-compatible server |
| Editor | App menus, searchable library, stage with click/drag actors, inspector quick actions, timeline, syntax-highlighting code editor with autocomplete, templates, projects, help, light/dark |
| Export | WebCodecs → own MP4 muxer (H.264 / HEVC, AAC / Opus), runs in a Web Worker |

Extra tools: `tools/gallery.html` (rig gallery: every character, clip strip, face sheet, builds) and
`python3 scripts/browser-test.py` (headless Chrome end-to-end incl. a mock TTS server and MP4 checks).

## Adding assets

Drop a JSON file in `src/assets/{rigs,characters,scenes}/` (or edit `voices.json`), run
`node scripts/build-manifest.mjs` (Netlify does this on deploy) and it appears in the editor.
`tests/assets.test.mjs` checks every character, palette key, slot option and clip reference.
